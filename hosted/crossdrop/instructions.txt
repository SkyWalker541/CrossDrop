CrossDrop — setup instructions

Send books to this reader from a KOReader device over Wi-Fi or a direct
connection — no cable needed.

1 · Install the KOReader plugin

On the device running KOReader (Kindle, phone or tablet):

1. Copy the crossdrop.koplugin folder into koreader/plugins/ on that device.
2. Restart KOReader. (The plugin also ships as CrossDrop-Plugin.zip.)

2 · Start receiving on this reader

Main menu → File Transfer, then pick one of the two modes:

- Join a Network — for transferring over your Wi-Fi network.
- Create a Hotspot — for a direct connection, no router needed.

The address you need is shown on this File Transfer screen.

3 · Finish the setup on your KOReader device

Switch to the device with KOReader, open the gear menu → CrossDrop, and in the
dashboard:

- Connections → Set WiFi IP... — enter the address shown on the reader's
  Join a Network screen, or
- Connections → Set HotSpot IP... — for the reader's hotspot mode, save the
  address shown on the Create a Hotspot screen.

Then go to the Send tab and tap the book you're reading.

All transferred files are placed on this reader in the CrossDropped Files
folder — including these instructions.
