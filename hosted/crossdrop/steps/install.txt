1 · Install the KOReader plugin

On the sending device (an e-reader, phone or tablet running KOReader):

1. Copy the crossdrop.koplugin folder into koreader/plugins/ on that device.
2. Restart KOReader.
3. Open the gear menu → CrossDrop.

The plugin also ships as CrossDrop-Plugin.zip for easier copying.

If this is the first time, keep this guide open on the reader while you set up
KOReader — you will read the device's address off a File Transfer screen in
the next step.
